L'essentiel

Récursion, listes et ordre supérieur

Presque tout exercice sur les listes se résout avec le même squelette : un match avec un cas [] et un cas e :: l. Ce qui change, c'est ce qu'on renvoie sur la liste vide et ce qu'on fait de e.

1. Définir des valeurs et des fonctions

let x = 5                          (* une valeur *)
let succ x = x + 1                 (* une fonction *)
let succ = fun x -> x + 1          (* la même chose, écrite avec fun *)
let rec fact n =                   (* rec : la fonction s'appelle elle-même *)
  if n = 0 then 1 else n * fact (n - 1)
  • let rec seulement si la fonction s'appelle elle-même (pas pour find_power, qui appelle loop).
  • L'appel s'écrit sans parenthèses ni virgules : f x y, pas f(x, y).
  • Un argument calculé se met entre parenthèses : loop p f (f x).
  • Un if a toujours son else, et les deux branches ont le même type.

2. Définitions locales : let … in

let find_power x n =
  let p y = y >= n in        (* p n'existe que dans find_power *)
  let f y = y * x in
  loop p f 1

Une fonction définie à l'intérieur voit les paramètres de la fonction englobante : p utilise n, f utilise x.

4. Types et exceptions

  • int, bool (true/false en minuscules), string, 'a list, couples int * string.
  • Les éléments d'une liste sont séparés par ; : [1; 2]. Avec une virgule, [1, 2] est une liste qui contient un couple.
  • map a le type ('a -> 'b) -> 'a list -> 'b list : 'a veut dire « n'importe quel type ».

5. Le squelette récursif

let rec f lst = match lst with
  | [] -> (* cas de base : ce qu'on renvoie quand il n'y a plus rien *)
  | e :: l -> (* on traite e, et on rappelle f sur le reste l *)
Deux questions à se poser 1. Que renvoie-t-on sur la liste vide ? La récursion y arrive toujours : ce cas décide du résultat pour toutes les listes. 2. Que fait-on de e, et comment combine-t-on avec l'appel sur l ?

7. Trois façons de combiner e avec l'appel récursif

Construire une liste (map, filter) : on met e devant le résultat. L'ordre est conservé.

| e :: l -> f e :: map f l

S'arrêter dès qu'on sait (for_all, exists, find).

| e :: l -> p e || exists p l

Accumuler dans une fonction auxiliaire : empiler en tête inverse l'ordre, il faut un rev à la fin.

let f lst =
  let rec aux lst acc = match lst with
    | [] -> rev acc
    | e :: l -> aux l (e :: acc)
  in aux lst []

Renvoyer un couple (partition, unzip, count) : on traite d'abord le reste et on découpe son résultat.

| e :: l ->
    let (a, b) = f l in     (* 1. traiter le reste *)
    ...                     (* 2. placer e dans le couple *)

10. Méthode pour attaquer un exercice

  1. Lire le type de retour : liste, booléen, élément ou couple ? Il fixe le cas de base.
  2. Chercher l'exercice qui ressemble dans le récap.
  3. Écrire le cas de base, en sachant que tous les appels y arrivent.
  4. Écrire le cas e :: l : que fait-on de e, et l'appel avance-t-il bien ?
  5. Vérifier les motifs : tous les cas sont-ils couverts ?
  6. Dérouler à la main sur trois éléments.
  7. Ajouter des exemples, dont la liste vide.
